# contact

シンプルなお問い合わせフォームの練習用ファイル。

## 概要

PHPだけ（外部ライブラリ不使用）で作った、お問い合わせフォームです。

- お名前・メールアドレス・件名・お問い合わせ内容を入力して送信できる
- 未入力・文字数超過・メールアドレスの形式不正をチェックし、エラーがあれば入力欄の下にメッセージを表示する
- 送信に成功すると、その場で入力内容を確認表示する
- 過去の送信内容を最新10件まで保存し、一覧の「詳細」を押すと個々の内容を確認できる

## 工夫した点

 

データを１０件保存し、画面下に履歴として表示できるようにした
エラーで戻っても入力済みの内容が戻らないようにした



- **エスケープの徹底**：ユーザーが入力した値を画面に出力する箇所はすべて `htmlspecialchars()` を通し、XSS（意図しないHTML・スクリプトの埋め込み）を防いでいる。
- **文字数制限のサーバー側チェック**：`maxlength` 属性だけでなく、`mb_strlen()` を使ってPHP側でも文字数を検証し、フォームを経由しない不正なリクエストにも対応できるようにした。
- **アクセシビリティ**：エラーがある入力欄には `aria-invalid` と `aria-describedby` を付け、スクリーンリーダー利用者にもエラー箇所が伝わるようにした。あわせてエラー時は枠を赤く表示し、視覚的にもわかりやすくしている。
- **送信履歴と個人情報保護**：送信内容は `data/submissions.php` に保存しているが、ファイル冒頭に `exit;` するガード行を入れることで、このファイルに直接アクセスされても中身（名前・メールアドレスなど）が漏れないようにした。あわせて `.gitignore` で `data/` をGit管理対象から除外している。
- **JSなしの詳細表示**：履歴の「詳細」ボタンは、JavaScriptを使わずHTML標準の `<details><summary>` タグだけで開閉できるようにした。
- **初心者向けの日本語コメント**：あとで読み返したときに処理の意図がすぐわかるよう、各ブロックに日本語コメントを付けている。

## 学んだこと

- `$_POST` で受け取った値は必ず信頼できないものとして扱い、表示前のエスケープ・保存前のバリデーションが必要であること。
- ファイルに保存したデータをWeb経由で直接見られてしまうと、意図せず個人情報が漏れる危険があること。また、`include` でPHPファイルを読み込む方式は、短時間に連続で書き換えるとキャッシュの影響で古い内容が返ってくることがあり、単純な保存用途でも読み込み方法を選ぶ必要があること（実際に開発中、連続送信時に履歴が欠落する不具合が発生し、`file_get_contents` を使う方式に変更して解決した）。
- `aria-invalid` や `aria-describedby` など、見た目だけでなく支援技術（スクリーンリーダー等）にも配慮したマークアップの書き方。
- `<details><summary>` を使うと、JavaScriptなしでも開閉できるUIを簡単に実現できること。

## 内容

- `contact.php`：お問い合わせフォーム本体（フォーム表示・バリデーション・送信履歴の保存と表示）
- `data/submissions.php`：送信履歴の保存先（自動生成。Git管理対象外）

## 実行方法

```
php -S localhost:8000
```

起動後、`http://localhost:8000/contact.php` にアクセスする。
